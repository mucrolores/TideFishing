# Tide Fishing

一個單頁式潮汐資訊 Dashboard，用來顯示中央氣象署提供的真實潮汐資料，並根據潮汐時間與日期條件，推薦適合釣魚的時段。

## 功能

- 顯示滿潮與乾潮時間表
- 以潮汐曲線呈現潮位變化
- 支援查看：
    - 今天
    - 未來 7 天
    - 未來 30 天
- 在圖表上標示推薦釣魚時段
- 強調每日 `00:00` 換日線
- 根據以下條件計算釣魚推薦分數：
    - 是否為週末
    - 滿潮時間是否落在 `12:00–18:00`
    - 滿潮時間是否接近下午時段
    - 日期是否接近目前時間
- 支援切換不同潮汐預報地區
- API key 會儲存在瀏覽器 `localStorage`
- 若已儲存 API key，開啟頁面時會自動載入真實資料
- 單頁式 Dashboard 版面，桌面版不需整頁捲動

## 使用方式

1. 至中央氣象署氣象資料開放平台申請 API 授權碼。
2. 開啟 `hsinchu_tide_fishing.html`。
3. 點擊右上角設定按鈕。
4. 輸入 API key 並選擇地區。
5. 點擊「擷取真實資料」。

成功載入後，潮汐曲線、時間表與釣魚推薦會自動更新。

## 資料來源

本專案使用中央氣象署開放資料：

- 資料集：`F-A0021-001`
- 內容：未來一個月潮汐預報
- 主要欄位：
    - `DateTime`
    - `Tide`
    - `TideHeights`
    - `AboveLocalMSL`

## 注意事項

- 本頁面為純前端 HTML，API key 會儲存在使用者瀏覽器中。
- 不建議將私人 API key 直接寫入公開的 HTML 原始碼。
- 若透過 `file://` 開啟時遇到瀏覽器限制，可改用本機 HTTP server：

```bash
python -m http.server 8000
```

接著開啟：

```text
http://localhost:8000
```

- 釣魚推薦僅依日期與潮汐時間進行簡單評分，未納入風速、降雨、浪高、氣壓與實際釣場狀況。
- 實際出發前仍應確認天氣、海象與現場安全。
